Project Purpose

The purpose of this website is to present boxing as a useful hobby for fitness, discipline, confidence, and personal growth. The website is built using semantic HTML, external CSS, and JavaScript.

Design Process

The design uses a simple layout with a header, navigation menu, content sections, article cards, and a footer. The colors were chosen to match a boxing theme while keeping the page easy to read.

HTML

Used for page structure, semantic elements, navigation, text, images, and iframe media.

CSS

Used for layout, colors, spacing, responsive design, and card styling.

JavaScript

Used for button interaction and contact form validation.
