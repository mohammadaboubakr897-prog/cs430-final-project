# Boxing Training Hub

This is a CS430 final group project website about boxing training.

## Pages

- Home page: `index.html`
- About page: `about.html`
- Contact page: `contact.html`

## Features

- Semantic HTML
- External CSS
- Responsive design using Flexbox and Grid
- JavaScript DOM manipulation
- JavaScript event handling
- Contact form validation
- Image and iframe multimedia

## Folder Structure

- `css/` contains the stylesheet
- `js/` contains the JavaScript file
- `images/` contains website images
- `docs/` contains the final report

## GitHub Pages

The website can be deployed using GitHub Pages.
